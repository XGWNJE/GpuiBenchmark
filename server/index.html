测试协议与计分

测试内容

gpui-benchmark-v1 包含四档负载的原位更新与自动滚动，以及浅色、深色样式场景。每个场景重复 3 次，共 30 项，每项预热 3 秒、测量 20 秒。

分数计算

服务端根据各项原始统计重新计算分数。60 FPS、P95 在帧预算以内、更新全部处理时，基准为 1000 分。高刷新率设备可以超过这一分数。

mean(FPS × min(1, 帧预算 / P95) × 已处理更新 / 已生成更新) / 60 × 1000

数据含义

帧率与 P95 来自应用的 CPU 侧帧回调间隔。设备温度、系统刷新率和后台负载会影响成绩。页面记录客户端自报的设备和统计，服务端检查格式、测试完整性与计分，未提供设备身份认证或防作弊证明。

参与排名

完整完成标准协议的真机成绩参与排名。演示、自定义、模拟器、取消或不完整的记录保留原因供查看。相同厂商与机型采用最高分，重复提交同一记录不会新增成绩。

数据与隐私

公开内容包括厂商、机型、Android 版本、屏幕、刷新率与测试统计。请避免在机型等字段填写个人信息。提交接口按网络地址临时限流，地址仅保存在有界内存中。
